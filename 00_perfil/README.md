# 00_perfil — Quién eres y cómo está configurado Copitori

Esta carpeta es el "cerebro de identidad" del copiloto. Copitori la lee al inicio de cada sesión.

| Archivo | Qué contiene |
|---|---|
| [identidad.md](identidad.md) | Quién eres, tu rol, trato e idioma. Incluye el interruptor `estado_configuracion`. |
| [organizacion.md](organizacion.md) | Qué hace tu empresa/área, sector, a quién sirves, glosario. |
| [config_copiloto.md](config_copiloto.md) | Qué módulos están activos y qué herramientas tienes conectadas. |

> El asistente de configuración (primer arranque o `/configurar`) rellena estos tres archivos.
> Puedes editarlos a mano cuando quieras; Copitori los respeta como fuente de verdad.
